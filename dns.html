Cloudflare DNS Records Guide

            
Connect any subdomain to GitHub Pages. Changes take 5-15 minutes.


            

              

                
1

                

                  
Note down your GitHub Pages URL

                  
Copy the GitHub Pages URL of the repo:

                  

# GitHub Pages URL format
https://USERNAME.github.io/REPO-NAME
                  

                  
Find it under the repo's Settings → Pages.

                

              


              

                
2

                

                  
Go to Cloudflare DNS

                  
Login to Cloudflare → select the domain → open DNS.

                

              


              

                
3

                

                  
Add a CNAME record

                  
One CNAME record per subdomain:

                  

# Type: CNAME
# Name: blog  (or any subdomain name)
# Target: USERNAME.github.io
# Proxy status: Proxied (orange cloud ON)
                  

                  
That's it! Cloudflare propagates automatically.

                

              


              

                
4

                

                  
Verify

                  
Open Deploy and press Check DNS. Allow 5-15 minutes.
