Point subdomains to GitHub Pages — step by step

Connect a subdomain to GitHub Pages on Hostinger

Ye steps kisi bhi subdomain (jaise blog.example.com) ko apne GitHub Pages site se jod denge. DNS changes ko reflect hone mein 24–48 ghante lag sakte hain.

1

Apna GitHub Pages URL note karein

Har GitHub repo jispe website hai uske GitHub Pages URL ko copy karein:

# GitHub Pages URL format https://USERNAME.github.io/REPO-NAME

GitHub repo ke Settings → Pages mein jaakar URL dekh sakte hain.

2

Hostinger panel kholen

hPanel (hPanel.hostinger.com) mein login karein. Apni website / domain ke saath DNS Zone add karne ke liye:
Websites → Manage → Domain → DNS / Nameservers → DNS Zone Editor.

3

A records add karein (points to GitHub)

Apne har subdomain ke liye 4 A records add karein — Host me subdomain ka naam (jaise blog) daalein, aur in 4 GitHub IPs ko add karein:

185.199.108.153 185.199.109.153 185.199.110.153 185.199.111.153

Iska matlab: blog. aapke domain ka ek naya record jo GitHub ko point karta hai.

4

CNAME record add karein

Aapke repo ke naam se CNAME add ho sakta hai. Host me CNAME select karein:

# Host www #or apna subdomain blog # Value / Points to (apna GitHub Pages URL) USERNAME.github.io
5

Verify ho jaye

Hexane / Inquire ke baad browser mein blog.yourdomain.com khol ke check karein. DNS propagate hone mein thoda time lagta hai.

GitHub Pages mein custom domain set karna

Har repo ko uski subdomain se jodne ke liye:

1

Repo open karein

Jis website ka subdomain banana hai uska GitHub repository kholen.

2

Settings → Pages

Repo ke Settings mein jayen, left sidebar mein Pages par click karein.

3

Custom domain set karein

Custom domain section mein apna subdomain likhein (jaise blog.yourdomain.com) aur Save dabayen. Phir Enforce HTTPS checkbox on karein.

4

CNAME file (optional)

Best practice: apne repo ki root mein ek CNAME file banayen jisme sirf apna subdomain ho:

blog.yourdomain.com
