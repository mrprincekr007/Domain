Cloudflare DNS Records Guide

            
Ye steps kisi bhi subdomain (jaise blog.princehacks.online) ko apne GitHub Pages site se jod denge. DNS changes ko reflect hone mein 5-15 minute lag sakte hain.


            

              

                
1

                

                  
Apna GitHub Pages URL note karein

                  
Har GitHub repo jispe website hai uske GitHub Pages URL ko copy karein:

                  

# GitHub Pages URL format
https://USERNAME.github.io/REPO-NAME
                  

                  
GitHub repo ke Settings → Pages mein jaakar URL dekh sakte hain.

                

              


              

                
2

                

                  
Cloudflare DNS mein jaayen

                  
Cloudflare Dashboard mein login karein → princehacks.online select karein → DNS tab mein jaayen.

                

              


              

                
3

                

                  
CNAME record add karein

                  
Har subdomain ke liye ek CNAME record add karein:

                  

# Type: CNAME
# Name: blog  (ya koi bhi subdomain naam)
# Target: USERNAME.github.io
# Proxy status: Proxied (orange cloud ON)
                  

                  
Bas! Cloudflare auto-propagate kar dega.

                

              


              

                
4

                

                  
Verify karein

                  
Deploy tab pe jaake Check DNS button dabayein. DNS propagate hone mein 5-15 minute lagte hain.
